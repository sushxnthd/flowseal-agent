# Confirmatory inference addendum: template-cluster sensitivity

Frozen before inspecting any confirmatory outcomes.

The primary unit remains the predeclared task instance: 32 concrete tasks, with both models and both interfaces retained within every resampled task.

Because those 32 instances instantiate eight frozen operation-pair templates four times each, the manuscript will also report a stricter secondary sensitivity analysis for the two principal behavioral effects:
1. macro-minus-fine endpoint success;
2. macro-minus-fine P_fine score.

For this secondary analysis, the four task instances sharing an operation-pair template are averaged first, yielding eight template-level contrasts, and the bootstrap resamples those eight template clusters.

This sensitivity analysis is not substituted for the primary analysis and is not used selectively based on whether its interval excludes zero. Both primary task-instance and secondary template-cluster intervals will be reported.
