# Predeclared template-cluster sensitivity

Committed before official sharded confirmatory outcomes are accessible.

The primary inferential unit remains the 32 concrete task instances, as frozen in CONFIRMATORY_PROTOCOL.md.

Because those instances are generated from eight operation-pair templates repeated four times, we additionally predeclare a stricter secondary sensitivity analysis:

1. Assign each task to one of the eight operation-pair templates used by the generator.
2. Within each template, average the target contrast across its four concrete task instances and across the two models where appropriate.
3. Bootstrap the eight template-level averages with replacement using 10,000 resamples.
4. Report this template-cluster interval for the primary endpoint-success interface contrast and the primitive-score interface contrast.
5. Treat this as a sensitivity analysis, not a replacement for the primary task-cluster analysis.

No template will be removed or reweighted based on outcomes.
